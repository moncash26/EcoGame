# ECO: Tú contra ti

Juego de un dedo. Recoge orbes durante 20 segundos. Cada ronda que sobrevives regresa como un *eco* que repite exactamente tu recorrido. No te toques a ti mismo.

**Jugar:** https://moncash26.github.io/EcoGame/

**Novedades**
- Ranking de mejores jugadores (por puntos y por nivel) y tabla de récords personales.
- ✦ Luz: se gana superando rondas, con bonos por nivel, bono diario y anuncios con recompensa.
- Ítems canjeables: Rompe-eco (rompe al eco que te toca), Congelar e Imán.
- Tienda premium de bajo costo: Onda expansiva, packs y "Sin anuncios".

Prototipo web (HTML + canvas, sin dependencias). Anuncios y compras son simulados. El ranking se guarda en cada dispositivo; el ranking global entre jugadores requiere conectar un servidor.
